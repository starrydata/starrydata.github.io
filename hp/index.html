What is Starrydata

Starrydata is an open data project that extracts and structures experimental data from graphs in inorganic materials science papers, making them freely reusable by researchers worldwide. Rather than a single project, it is a federation of research teams — each contributing curated data to a shared repository and together building a large open dataset that anyone can use.

How it works

Collect→Accumulate→Utilize

Experimental graphs from published papers are manually digitized and stored together with sample metadata in a single database. The resulting structured data is ready for visualization, download, and machine learning.

A Large-Scale Database

Patterns invisible in any single paper emerge when tens of thousands of samples and curves can be explored together.

Performance distributions across material families, composition–property correlations, outliers and unexplored composition space, and training / benchmark datasets for machine learning — these are the analyses that only a large-scale database makes possible.
